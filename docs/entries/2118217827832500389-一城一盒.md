## 一城一盒

### 概述

如果把一座城市装进盒子里，你会放什么？一处地标、一份美食、一件手工艺品，还有那些只有在当地生活过才熟悉的小东西。上传六格空盒底板，输入一个城市或地区，就可以尝试制作一盒属于当地…

### 提示词

```
使用上传的六格空盒作为空间结构参考，为【国家／城市／地区】创作一张 3:4 竖版地域风物微缩收藏礼盒摄影作品。

先研究当地真实存在的建筑、地貌、材料、手工艺、色彩、植物、美食和生活器物，提取具有地域识别度的元素，形成统一的视觉语言。

保留参考图中六个独立分格、基本比例、打开状态和四分之三俯视视角。根据当地建筑与工艺重新设计盒盖、外包装、分隔板和内衬，让材质、纹样与地域文化相呼应，包装结构符合真实制作工艺。

六个格口各放一件真实可考的当地微缩藏品，涵盖代表性建筑、美食或农产品、手工艺或生活器物，以及自然或人文特色。主体不重复，大小适合格口，稳定放在内衬上，有自然的接触阴影。

每件藏品配一张小巧清晰的收藏标签，写上「当地语言名称＋英文名称」，不遮挡主体，标签样式与礼盒统一。

将礼盒放在具有当地特色的真实空间中，例如民居、庭院、手工作坊或自然观景台。结合当地材料、植物和自然光，背景有层次但不抢主体，也不重复盒内藏品。

礼盒占画面约 70%—80%，六格全部可见。真实表现纸张纤维、木材、石材、陶瓷、织物和食物等微缩材质。画面下方留白，加入【城市中文名称】和【当地语言或英文名称】，文字准确、清晰。

避免分格合并、物件悬浮、地标重复、虚构特产、无关文化符号、标签乱码、廉价塑料感和拥挤背景。
```
