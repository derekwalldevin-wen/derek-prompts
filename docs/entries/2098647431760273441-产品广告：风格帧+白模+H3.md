## 产品广告：风格帧+白模+H3

### 概述

### 提示词

```
上传图1作为产品身份的唯一参考，制作一段12秒、16∶9的产品广告。

第一步｜生成广告风格帧

严格保留产品的外形比例、包装结构、Logo位置、标签文字、材质和颜色。

将产品放入【冰面、黑色镜面、液态金属、东方园林或极简影棚】。产品占画面高度的40％至55％，保留展示空间和摄影机移动空间。

采用【指定光线与色彩】，建立产品主视觉。输出一张独立风格帧，不生成分镜板和多角度展示图。

第二步｜制作运动预演

根据风格帧在Blender中建立低精度白模。只复原产品外轮廓、承托平面、主要障碍物和摄影机位置。

设置一项主要产品动作【旋转、开合、升起、组装或穿越液体】，配合一次【推近、横移或低位抬升】。

在第0、3、7和12秒设置关键姿态，输出12秒白模预演视频。不要在这一阶段制作精细材质。

第三步｜完成视频渲染

将图1设为产品身份参考，将风格帧设为场景、构图、材质和光线参考，将Blender预演视频设为动作、速度、时间和摄影机参考。

生成12秒单一连续镜头。产品严格按照预演轨迹运动，保持图1中的外形、文字和结构。延续风格帧的背景、色彩、反射和投影。

加入真实接触阴影、材质高光变化、运动模糊和环境反馈。产品经过水面时产生涟漪，接触地面时产生阴影变化，部件打开时保持连接结构。

禁止产品变形、Logo漂移、包装文字变化、部件增减、悬浮穿模、运动方向改变、摄影机绕至背面、场景跳变和无关特效。
```
