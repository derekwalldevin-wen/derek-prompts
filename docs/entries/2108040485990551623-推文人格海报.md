### 提示词

```
不用露脸也能出片：把你平时发帖的语气，变成一张由你主演的 1960 年代复古电影海报。

AI 绘画每日一词｜推文人格海报

我也放了一张我自己的背影，你觉得符合你对我的印象吗？

怎么做：
1. 打开能出图的 AI（ChatGPT、Grok、豆包等都行）
2. 复制下面的提示词，把方括号里的内容换成你的账号名和 3–8 条最像你的帖子
3. 头像可以附，也可以不附
4. 片名不够像电影名就重跑，可以补一句「更毒舌」「更温柔」或「更赛博」

👇 完整提示词，直接复制：

请根据我的社交账号「[你的账号名]」和下面这些我发过的帖子，判断我的发帖人格，包括语气、执念、口头禅和常聊的话题，然后为我设计一张 1960 年代好莱坞复古电影海报，我是这部电影的主角。

我的帖子：
[帖子内容]
[帖子内容]
[帖子内容]

要求：
- 竖版 2:3
- 片名要像一部真实上映过的电影，不要出现「AI」「艺术」这类泛泛的词
- 从我的发帖语气里提炼一句宣传语，放在片名上方
- 主画面是一个能代表我性格的戏剧性场景；如果附了头像，就保留我的五官，没附就用剪影或背影
- 底部加一行仿真演职员表小字，把我常聊的话题写成「主演」「导演」的名字
- 石版印刷颗粒、褪色纸张、手绘字体的质感
- 不要水印

避坑：
- 片名写成「AI 艺术」就没味道了，要像电影名
- 帖子给得太少会出一张谁都像的脸，至少给 3 条
- 这个玩法卖的是你的性格，不是自拍

你的帖子人格是哪部电影？把海报发在评论区 👇

#AI绘画 #提示词 #AIart
```
