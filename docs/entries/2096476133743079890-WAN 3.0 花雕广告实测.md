```
0–4秒冷灰高级空间，透明薄酒盏中缓慢注入琥珀金花雕酒，100mm微距表现酒液透明度、折射与杯壁液滴。字幕“花雕 / AGED HUADIAO”“酒，要先有时间 / TIME FIRST AGES THE WINE”。
4–8秒完整蒸熟大闸蟹置于冷白石台，蟹壳自然珊瑚橙红，有极少蒸汽，厨师只露手轻轻打开蟹盖，第一次露出真实饱满橙金蟹黄。字幕“鲜 / THE SEA”“先熟，才醉 / COOKED BEFORE AGED”。
8–12秒熟蟹在冷白高级空间静置降温，蒸汽逐渐消失，一滴细小冷凝水在蟹壳表面形成，不结冰，不结霜。字幕“冷 / CHILLED”“把热退去 / LET THE HEAT FADE”。
12–17秒透明玻璃容器装满清澈琥珀色花雕醉汁，熟蟹缓慢进入液体，蟹壳与琥珀酒产生漂亮折射和波纹，摄影机短暂进入液体内部，拍红壳、金酒、玻璃折射和极少香料。字幕“醉 / IMMERSED”“让酒香慢慢进去 / LET THE AROMA SINK IN”。
17–21秒固定镜头表现熟蟹在花雕醉汁中安静浸渍，环境逐渐变为冷蓝灰色，酒液保持暖琥珀，偶尔极小气泡沿蟹壳上升。字幕“浸 / REST”“酒香需要安静 / AROMA TAKES TIME”。
21–25秒高级冷前菜桌边场景，醉蟹完整置于浅色石桌，旁边只有一个很小的花雕酒盏。服务者轻轻打开蟹盖，100mm微距同时展示珊瑚红蟹壳、橙金蟹黄、珍珠白蟹肉和少量琥珀醉汁，字幕“开 / REVEALED”。
25–28秒蟹钳被干净打开，红色外壳裂开后露出整块雪白湿润蟹钳肉，小银叉轻轻提起完整蟹肉，表面带极薄花雕汁，并与少量橙金蟹黄同框。字幕“鲜 / PURE”“醇 / AGED”。
28–30秒完整蟹钳肉置于月白瓷匙，旁边只有少量蟹黄和几滴琥珀花雕汁，背景有极淡冷雾，酒液在匙边形成一滴即将落下，突然切纯琥珀金。最终字幕“陈年花雕熟醉蟹 / HUADIAO DRUNKEN CRAB”“花雕入鲜，一蟹微醺 / AGED IN AROMA. FULL OF THE SEA.”“食色 / EDIBLE LUXURY”。
```
