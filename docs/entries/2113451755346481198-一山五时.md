## 一山五时

### 概述

同一座山，左边刚醒，右边已经入夜。一条路，也可以同时走过春夏秋冬。 今天把时间切成几片，放进同一个空间。适合旅行海报、自然主题封面和场景概念图，标题也可以跟着时刻变色。

### 提示词

```
生成一张独立3:4竖版艺术摄影作品，场景为【场景】。

固定同一个机位，把同一场景不同时刻的影像按【切片布局】拼成连续空间；时间依次为【时间序列】。各片保留相同焦距、透视和尺度，【固定结构】必须在接缝处对齐贯通，只改变光线、天气与自然状态，不复制成多个完整场景。切片边界清楚、无边框无间隙，不做平滑渐变，也不拉伸纹理或弯折地面。采用【机位构图】，在【留白】保留至少四分之一连续安静负空间。色彩与材质为【色材】，每片内部的光照、阴影和反射与对应时刻一致，细节真实，电影摄影质感。

文字模式为【文字模式】。海报模式仅出现中文【中文标题】和英文【英文标题】，使用【字形层级】，按【文字位置】排布；字保持完整可读，通过【文字变化】呼应时间切片，配色为【文字配色】，不填满负空间，不加其他文案。无字模式忽略全部标题参数，全图不出现任何文字。只输出一张完整作品，无对照图、网格合集、商标、水印、时间刻度、说明小字；不要镜面碎片、独立悬浮板、重复建筑、故障拖影或复制现有摄影作品。

示例参数

【场景】高山湖泊和一座连绵雪峰

【切片布局】主景从左到右五道竖向等宽切片，顶部天空保持安静整体

【时间序列】晨光粉紫、上午青蓝、正午冷白、日落橙金、深夜靛蓝

【固定结构】山脊轮廓与湖岸线

【机位构图】远景平视，山脊在下半部，湖面占底部四分之一

【留白】上方三分之一空旷天空

【色材】粉紫、冰蓝、琥珀金与靛蓝，岩石、雪面和湖水清楚

【文字模式】海报

【中文标题】一山五时

【英文标题】TIME RANGE

【字形层级】中文超大现代宋体，英文窄体无衬线、约中文一半大

【文字位置】中文横跨天空下沿，英文左对齐放中文上侧，与山峰保持距离

【文字变化】中文整行笔画对齐，跨时间边界只变字色，不错位断字；RANGE兼指山脉与范围

【文字配色】中文由深靛蓝跨到暖白，英文深靛蓝

📌一句话总结
景物的位置不动，让时间在画面里换班。
```
