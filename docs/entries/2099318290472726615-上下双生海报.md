### 提示词

```
请将我上传的照片制作成一张独立的高级设计海报，不要多图拼接，每张照片单独输出。

整体为3:4竖版构图，画面严格分为上下两个区域，高度各占50%，比例为1:1。

上半部分保留原始照片，保持主体身份、结构、姿态、真实质感、自然光影和原有色彩氛围，仅进行轻微高级调色，使其具有艺术杂志、独立出版物与展览图像质感。为适配画幅，可以自然补足环境背景，但不得拉伸、扭曲或改变主体。

下半部分基于同一张照片，提取其中最具识别性的主体、轮廓、结构、姿态与叙事关系，重构为现代主义几何平涂插画。

插画要求：
不是用几何线条描边，而是直接将主体压缩为矩形、梯形、三角形、圆形及少量自由块面，用最少形状保留最关键的身份特征，使人一眼能够认出原物。

整体采用明显的平面化空间表达：
弱化真实透视、体积和写实光影，主要通过前后遮挡、尺度变化、色块叠压与高低关系建立空间。

复杂的人物、建筑、车辆、植物、器物或环境细节要主动合并为少数大形体系统，重复元素归纳为统一色块，不逐一描绘。

若原图不是城市场景，不要强行城市化，而是用同样的几何化方法重构人物、动物、静物、自然景观或其他主体。

构图强调：
大块面比例、视觉重心、层叠关系、正负形、色彩节奏与留白秩序。主体可以偏心、裁切、遮挡或自然展开，但必须保持清楚的叙事核心。

造型采用：
大面积平涂色块，轻微手绘不规则边缘，哑光水粉或丙烯质感。颜料表面细腻、柔和，略有手工覆盖感。避免数字渐变、真实材质模拟、复杂阴影、照片滤镜和光滑矢量感。

最终效果：
上半部分像高级摄影海报，下半部分像现代主义几何拼贴插画，两者对应同一主体，形成清晰的上下对照关系。
```
