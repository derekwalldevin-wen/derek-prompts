## 单点换色实验

### 概述

用AI充当你的审美验证先行官？ 同一间房，只把一面墙换成赭红色，你会更想住进去，还是立刻想改回来？ 先别急着让AI“爆改”。这次只准动一处，看看颜色改变了后你是不是满意。

### 提示词

```
根据上传的【原场景照片】，完成单点换色实验，输出一张独立3:4竖版图片。仅将【唯一改色区域】的底色改为【目标颜色】，保留原有材质、纹理、磨损和明暗，不把粗糙面变成光面。锁定【三个核对点】；其他物件、建筑结构、镜头、透视、光向、曝光与天气均不改变，不新增装饰或整理杂物。严格执行唯一输出方案：【输出方案】。有文字时仅出现中文“【中文标题】”和英文“【英文标题】”，按照【文字设计】排版；中文为主，英文约五分之一大，标题仅一个指定字使用目标色，其余炭黑，以文字的一处变色呼应实验。字形完整清楚，不遮挡核对点。画面保持自然建筑摄影质感、真实接触阴影和克制配色，不作全图滤镜，不换家具、不改灯光、不拉伸空间。禁止额外文案、商标、水印和装饰性伪文字。

示例参数
【原场景照片】上传的客厅照片
【唯一改色区域】沙发后方整面实体墙，不含左侧窗框或踢脚线
【目标颜色】深赭红哑光墙漆
【三个核对点】拱窗轮廓位置、沙发轮廓位置、小圆木边桌位置
【输出方案】对照海报：暖白纸感上方四分之一连续留白作标题，下方将原照片和改色结果分别以4:3横图等大居中排列，原图在上、结果在下，每幅宽约画布三分之二，保留左右留白，原图不改色，不裁切不拉伸，不加标签
```
