## 狭缝扫描拉伸

### 概述

花瓣突然被拉成一条很长的色带，橙子的果肉变成了细密的竖线。熟悉的东西还认得出来，却像在画面里留下了一段时间。 今天试试用AI模拟扫描时移动物件的效果。留下一个清晰的辨认点，其余部分交给线条延伸，适合做无字海报、音乐封面和艺术配图。

### 提示词

```
生成一张独立3:4竖版无字艺术图，主体为【主体】，保留【识别特征】。模拟物件在狭缝扫描中移动形成的时间拉伸影像：保留约三分之一清晰可辨的实体区域，从【拉伸起点】连续延展出密集、细直、彼此平行的扫描色线，按【路径】铺成一片平面色带。色线必须从主体自身的颜色与纹理延续，起点衔接清楚；拉伸区占主体影像的一半以上，不是物体背后另加彩带。沿扫描方向可有一次柔缓转向，仍保持线束顺序，末端干净收束或截断。整体构图为【构图】，使用【配色与背景】。正对画面，平面影像，清晰部分有真实材质细节与细腻柔光，拉伸部分像高分辨率数字扫描，保留轻微采样纹理，不虚化成普通运动模糊。至少四分之一画面为安静留白，精密构成与浓郁但克制的色彩，艺术摄影图录质感。只输出一张完整作品，无文字、字母、数字、标志、水印、边框、原图对照或拼贴；不要独立丝带、立体螺旋、液体、烟雾、霓虹、像素故障块或多个重复主体。
示例参数 【主体】一朵橘红非洲菊 【识别特征】完整圆形花盘与放射状窄花瓣 【拉伸起点】花朵下侧边缘 【路径】垂直向下后缓缓向左弯出，花瓣的橘红、金黄与花盘的深褐成为平行线 【构图】花朵位于右上，扫描轨迹落向左下，左上宽留白 【配色与背景】朱红、橘金、深褐，温暖象牙白背景

🔁延伸玩法
1、食物：柑橘分瓣、果皮和果肉自带色差，拉长后能形成清楚的线束。
 2、器物：保留海螺的开口、唱片的圆弧，让拖影延续原来的纹理。
 3、肖像：留住侧脸，从后脑与衣领延伸色线，避免五官一起变形。
📌一句话总结
保留一处清晰，让其余纹理把时间拉长。
```
