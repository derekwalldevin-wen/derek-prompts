## 灰盒预演

### 概述

AI视频最费时间的，往往不是画面不够精致，而是镜头一开始就没想清楚。

- Blender

### 示例

见 X 原帖媒体：https://x.com/derek_wall90176/status/2104058766652248395

### 提示词

```
以图1的灰盒预演为唯一镜头与动作参考，生成一段10秒、9:16的电影感视频。
严格保留原参考中的：
- 摄像机位置、焦段感与运动路径
- 人物和道具的位置、比例及朝向
- 每个动作发生的顺序与时间节点
- 前景、中景、背景的空间关系
- 遮挡、进出画和镜头停顿
将灰盒中的占位模型替换为完整角色、车辆、建筑和环境，角色身份参考图2，整体美术风格参考图3。
先准确还原空间与镜头，再增加材质、光影、粒子和环境细节。动作连贯，速度自然，空间关系稳定。
不要改变构图，不要重新设计运镜，不要让人物瞬移，不要交换动作顺序，不要擅自增加环绕镜头，不要生成重复角色或漂移物体。
```
