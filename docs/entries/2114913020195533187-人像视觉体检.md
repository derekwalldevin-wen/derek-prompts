## 人像视觉体检

### 概述

你有没有想过，把自己的照片丢给 AI，它不负责把你“变漂亮”，而是像一个造型师、摄影师和视觉设计师坐在一起，直接把你的脸做成一张视觉分析报告。 什么颜色更衬你？ 什么发型更适合你的脸型？

### 提示词

```
根据【上传的人物照片】，严格保持人物身份一致，保留真实五官比例、年龄特征、肤色、脸部结构和个人辨识度，不进行过度美化，不改变人物身份。
将人物制作成一张专业的 「Portrait Visual Audit｜人像视觉体检」高级视觉分析板。

画面中央保留人物真实半身肖像，呈现自然、干净、高级的时尚杂志人物测试照质感。

围绕主体建立多个清晰的视觉分析模块：

个人色彩
从人物肤色、发色、瞳色中分析并提取 5–7 个适合人物的主色，以真实布料、色卡、材质样本呈现。

发型测试
生成 3 种适合人物脸型与气质的发型小型对比肖像，必须保持同一人物身份，只改变发型设计。

服装轮廓
展示 2–3 种适合人物的领型、肩线或服装轮廓，以简洁服装草图、布料样本或局部穿搭测试呈现。

眼镜与配饰
展示适合人物脸型的眼镜框型、耳饰或其他关键配饰，不改变人物气质。
摄影光线
通过小型肖像测试展示适合人物的光线方向，例如自然侧光、柔和正面光、低反差电影光等。
视觉关键词
根据人物本身的真实特征，提炼 3–5 个简短的视觉气质关键词，例如：
「克制 / 清爽 / 知性 / 锐利 / 松弛」
同时提供对应英文小标签。

整体视觉参考：
高级时尚编辑的 casting board、
专业造型师 moodboard、
人物视觉研究档案、
设计师工作台。
采用精致的编辑设计网格，大量留白，信息层级清楚；真实照片、布料色卡、发型测试照片、手绘线稿、摄影测试片和少量手写批注自然组合。
整体具有高级杂志、视觉研究档案和专业设计提案感。
画面中的文字只保留必要的短标题和标签，中英文双语，排版清晰，不出现大段文字。
3:4 竖版，高级编辑设计，真实摄影质感，高细节。
```
