## 时间静止·角色锁定短片

### 概述

做AI视频，角色场景锁定是最实用的基础入门，我用这一段「时间静止」短片教你怎么用 AI 锁定角色。 很多人单个片段都能做的很好，但是人脸在不同片段中老是容易变形，这原因就在于没有锁定参考角色。

### 提示词

```
生成一段30秒、16:9横版、写实电影质感的轻喜剧短片。一个女人为了挽救打偏的台球，偷偷暂停了时间，正准备挪动黑球，却发现对手也能在静止的世界里行动。两个人一本正经地争抢，意外恢复时间，当场被所有人看见作弊。全片无对白，用眼神、手部动作和声音停顿讲清楚故事。

参考素材：
@图片1只负责女主的脸、黑色短发、酒红针织上衣、炭灰长裤和左腕手表。
@图片2只负责男主的脸、黑色短发、墨绿衬衫、灰褐长裤和左腕手表。
两人都戴银色长方表壳、浅色表盘、棕色皮带的同款腕表。
@图片3负责台球厅的空间、陈设、灯光和色彩，以它为场景基准。
@图片4只辅助理解反向机位，家具位置以图片3为准。
@图片5负责两人互相识破时的表情关系与画面气氛，是剧情中段的参考，不作为开场。所有参考图都只提取对应内容，不把设定板、多视图或拼图带进视频。

深夜的复古台球厅，墨绿台呢、深色木质球桌、三盏绿色灯罩的暖黄吊灯，酒红卡座，门外透进一点雨夜蓝光。现场有两名坐在卡座的观众和一名吧台服务员。角色表演克制、自然，幽默来自小心思被识破，不做夸张鬼脸。

0—4秒：差一点就赢了
从女主瞄准黑8球的近景开场，她嘴角微微上扬，利落出杆。镜头顺着白球运动跟到黑球，白球撞击黑球，黑球朝角袋滚去，却擦过袋口，眼看要滑走。女主笑容消失，眼睛迅速瞥向自己的左腕。

4—7秒：按下暂停
切腕表近景，她用右手按下左腕表冠，发出清脆的“咔哒”。立即切回稍宽画面：黑球停止滚动，吧台服务员失手洒出的酒液和几颗水滴停在半空，卡座观众拍到一半的双手也停住。现场爵士乐、人声、雨声同时截断。女主轻轻呼出一口气。

7—12秒：偷改结果
摄影机跟随女主走到黑球附近的角袋旁，利用前景悬停的水滴与后景静止的人物，形成清楚的空间层次。她先看看服务员，再看看观众，确认他们都没动，露出一点得意。她俯身，用右手伸向停在角袋旁的黑球，准备把球放进袋里。此时男主暂时在画外。

12—17秒：另一只手
切黑球与女主手指的近景。就在她要碰到黑球时，男主的右手从画面另一侧伸入，先一步把球轻轻拿起来。镜头顺着他的手臂抬起，露出男主平静的脸。他慢慢抬起左腕，给她看同款手表，轻挑一下眉。
切女主反应，她看一眼他的表，再看他的脸，停顿半秒，嘴角那点得意彻底消失。背景水滴和人群始终保持原来的姿态。

17—23秒：谁也别想赢
进入两人同框的中景，女主在画面左，男主在画面右，两人都站在刚才的角袋附近。男主把黑球握在右手里，女主伸手去拿，他只把手移开一点，仍然若无其事地看着她。女主突然望向他身后，装出惊讶的样子。他下意识回头，她趁机抓住握球的手。两人的动作短促、轻巧，像一场安静的小较量。

23—26秒：误触
两人争着同一颗黑球，手停在角袋上方。女主抬起左手去挡他，交错的手指意外按到了她腕表的表冠。给这个误触一个短促、清楚的近景，“咔哒”再次响起。两人同时僵住，意识到不妙。

26—30秒：现场抓包
现场声音猛地回来，酒液落下，观众的手掌拍到一起，随后看清他们的动作，停止鼓掌。切稍宽的画面：两位主角站在角袋旁，正共同抓着同一颗黑球，作弊姿势一览无余。
他们先看向观众，再尴尬地对视，默契松手。黑球垂直掉进脚边对应的角袋，“咚”。留住两人装作无事发生的表情半秒，直接切黑。

声音与节奏：
开场只有店内低音量爵士乐、雨声、球杆击球和球体碰撞声。时间暂停后，这些环境声全部停止，只留下两位主角的呼吸、鞋底轻响、衣料摩擦和手碰球的声音。男主伸手拿球的瞬间不加夸张惊吓音效，让突然出现的另一只手自己制造反转。恢复时间时，环境声与酒液落下同步返回；最后黑球落袋声清晰、干脆。无旁白、无对白、无字幕。

连续性要求：
暂停的是周围世界，两位主角及被他们直接拿动的物品可以正常活动。黑球在被拿起之前始终接触台呢，全片只有一颗黑8球和一颗白球。冻结期间，背景人物、悬空酒滴和门外雨滴都固定在空间中的同一位置，摄影机运动可以产生视差，不做全画面慢动作。服装、发型、腕表佩戴位置保持一致；角色不瞬移，球不复制。手部动作清楚，手指自然。不要发光法阵、能量波、漂浮时钟或科幻界面。采用自然剪辑衔接，不强制一镜到底。
```
