# 每日同步用的 Grok 提示词

把下面整段丢给 Grok Bot（在已归档的 X 列表上跑），它会输出一份可以直接被
`tools/ingest_batch.py` 吃掉的 JSON。存成 `data/inbox/YYYY-MM-DD.json` 即可。

要点：**只要真正能粘贴到模型里的提示词**，不要 🔁延伸玩法 / ⚙️参数技巧 / 📌一句话总结 /
避坑 / 怎么用 / 评论区引导 / hashtag / 「完整提示词，直接复制：」这类发帖文案。

---

```
你是我的提示词归档助手。请从 @derek_wall90176 的 X 原创帖里，提取【今天新增】且带可复制
正文提示词的帖子，输出为 JSON 数组，不要任何解释文字、不要 markdown 代码块以外的内容。

只输出这个格式（数组，每条一个对象）：
[
  {
    "id": "帖子的 status id（x.com/.../status/<id> 里的数字）",
    "title": "短标题，6–12 个汉字，概括这条提示词做什么",
    "description": "一句话说明效果，40–80 字，用于卡片摘要",
    "category": "image 或 video",
    "models": ["通用图像模型"] 或 ["MiniMax"] / ["GPT Image / ChatGPT"] / ["DeepSeek"] / ["通用视频工作流"] 等,
    "date": "YYYY-MM-DD（Asia/Shanghai）",
    "x_url": "https://x.com/derek_wall90176/status/<id>",
    "prompt": "【只放真正能用的提示词原文】",
    "media_preview_urls": ["https://pbs.twimg.com/media/xxxx.jpg", "..."],
    "notes": ""
  }
]

关于 prompt 字段（最重要）：
1. 必须逐字保留原帖里可复制的提示词正文，不润色、不翻译、不合并、不补写。
2. 去掉所有发帖用的社媒文案，不要放进 prompt：
   🔁延伸玩法、⚙️参数技巧、📌一句话总结、📌避坑、💡怎么用、
   「怎么做：1… 2…」「完整提示词，直接复制：」「5分钟上手版」「完整版」这类上手说明、
   结尾的「把图片发在评论区 👇」「你试了哪一类？」、#AI绘画 #提示词 等 hashtag、
   以及开头的标题行（例如「XXX海报｜完整中文提示词」）。
3. prompt 从第一句真正的指令开始，到最后一个真正的参数/禁用项结束，保持原有分段和换行。
4. 如果一条帖子里同时有「短版」和「完整版」两段提示词，只保留信息更完整的「完整版」，
   并在 prompt 开头写一行「【完整版】」区分。

关于 media_preview_urls：
- 给原始 pbs.twimg.com 直链，不要给 X 页面链接；能取到原图就用不带参数的 .jpg（原始尺寸）。
- 只给这条帖子自己的配图，按帖子里的顺序，最多 9 张。

规则：
- 只收录有可复制文字提示词、且有配图的原创帖；纯讨论、返图、无正文、只有图片里才有文字的帖子跳过。
- 不要 OCR 图片里的字去凑提示词。
- 已有的旧帖不要重复输出（我按 id 去重，但请只给今天新发的）。
- 如果今天没有符合条件的新帖，只输出 []。
```
