## 影子剧场双生

### 概述

如果你的影子，不是现在的你，会是什么样？ 请基于我上传的照片，制作一张独立的 3:4竖版“影子剧场双生”海报

### 来源

[X 原帖](https://x.com/derek_wall90176/status/2101152440397828450) · 2026-09-19（Asia/Shanghai）

### 适配模型

- 通用图像模型

### 示例

见 X 原帖媒体：https://x.com/derek_wall90176/status/2101152440397828450

### 提示词

```
请基于我上传的照片，制作一张独立的 3:4竖版“影子剧场双生”海报。

画面上下严格 1:1 分割。

上半部分

完整保留原始照片。

保持：

同一个人物
同一张脸
同一个动作
同一个姿态
同一个场景
同一个拍摄角度
同一个构图

只做轻度调色，不改变原图内容。

下半部分

严格保持上半部分的：

人物身份、面部特征、发型、服装、动作、姿态、主体位置、场景、机位和构图不变。

只重新设计光线和影子。

使用一个明确的硬质主光源，让人物在墙面、地面或背景表面形成清晰的大尺度投影。

真实人物本身保持完全不变。

但人物身后的影子，转化为：

【未来的自己 / 动物 / 神话角色 / 建筑 / 植物 / 职业形象 / 产品结构】

影子必须：

从真实人物脚下或身体接触点自然产生
符合真实光源方向
符合透视关系
保持明确轮廓
与地面或墙面真实贴合
具有自然的明暗衰减
不能像后贴上去的图形

最终效果必须像：

真实人物站在那里，但投下的却是另一个身份的影子。

禁止：

换脸
改动作
改服装
改人物比例
生成第二个实体人物
把影子做成漂浮图案
使用霓虹描边
做成插画贴纸
出现错误光源方向
```
