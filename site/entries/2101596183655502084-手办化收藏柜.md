## 手办化收藏柜

### 概述

想看看自己真的被“做成手办”，摆在收藏柜里是什么样吗？

### 示例

见 X 原帖媒体：https://x.com/derek_wall90176/status/2101596183655502084

### 提示词

```
上传一张照片，然后直接输入：

基于上传照片制作一张3:4竖版“微缩手办双生”视觉。

画面上下严格1:1。

上半部分完整保留原始照片，保持人物/宠物的身份、脸型、发型、服装、动作、姿态和环境不变。

下半部分将同一主体转化为1/7比例真实实体收藏手办。

严格保持：
same identity
same face
same hairstyle
same outfit
same pose
same color scheme

不要Q版，不要动漫化，不要改变年龄和身体比例。

根据主体与场景自动选择合适的收藏材质：

日常人物 / 街拍：
高品质PVC + 树脂涂装

机能 / 科技 / 工业风：
压铸金属 + 磨砂ABS + 局部电镀

宠物 / 治愈类：
搪胶 + 哑光树脂 + 柔和毛发表面处理

旅行纪念：
树脂人物 + 微缩场景底座 + 透明水面/环境件

高定 / 礼服 / 艺术人物：
珠光树脂 / 陶瓷釉感 / 收藏雕像质感

手办需要具有真实分件、喷涂层次、材质反射、接触阴影和微缩比例感。

放置在真实桌面、收藏柜或展示台中，加入透明亚克力底座、浅景深和产品摄影布光。

最终必须像真实生产并拍摄的一只收藏手办，而不是缩小真人或普通3D角色。
```
