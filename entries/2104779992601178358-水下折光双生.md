## 水下折光双生

### 概述

普通照片，能不能直接拍出“人在水下”的感觉？ 可以。 不用去泳池。 不用去海边。 也不用真的把人泡进水里。 上传一张普通照片：上半保留原图。 下半人物还是这个人物，但整张照片像突然沉进了水里。

### 来源

[X 原帖](https://x.com/derek_wall90176/status/2104779992601178358) · 2026-09-29（Asia/Shanghai）

### 适配模型

- 通用图像模型

### 示例

见 X 原帖媒体：https://x.com/derek_wall90176/status/2104779992601178358

### 提示词

```
请基于我上传的照片，制作一张独立的 3:4竖版「水下折光双生」海报，画面上下严格 1:1分割。
上半部分：
完整保留原始照片，仅做轻微统一调色。
保持 同一人物、同一张脸、同一动作、同一服装、同一场景、同一机位、同一构图。
下半部分：
严格保持上半部分的 人物身份、面部特征、发型、服装、动作、姿态、主体位置、场景结构和构图不变，将同一画面重构为真实的 水下摄影效果。
加入：
- 真实水面折射
- 蓝绿色水下光感
- 水波折光
- caustic 波纹光斑
- 微小气泡
- 轻微漂浮感
- 柔和水体景深
- 真实水下颗粒感
要求：
- 主体脸部和核心轮廓仍然清晰可辨
- 水光必须沿皮肤、衣服、建筑或物体表面自然变化
- 可以有轻微头发或布料漂浮
- 整体要像真的在清澈水中拍摄
- 不是简单加蓝色滤镜
最终效果像：
同一张普通照片，突然被水面吞进去了一半。
禁止：
- 禁止换脸
- 禁止改动作
- 禁止换场景
- 禁止整张图变成纯蓝滤镜
- 禁止卡通水波
- 禁止夸张特效
- 禁止明显AI感
- 禁止失去人物真实身份

🔁延伸玩法
人物照
最适合做半身照、侧脸照、站姿照。
普通街拍一下就会变得很梦幻。
旅行照
建筑、街道、海边、泳池边都可以。
会很像“城市沉进海里”的感觉。
情侣照
人不变，只让两个人一起进入水下光感。
很容易出氛围感。
产品照
香水、手表、饮料、护肤品特别适合。
会很像高级广告图。

📌一句话总结
上传一张普通照片，让AI把它直接拍成水下大片
```
