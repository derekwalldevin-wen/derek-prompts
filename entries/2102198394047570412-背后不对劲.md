## 背后不对劲

### 概述

你有没有那种照片，本来挺正常，结果越看越觉得背后“不太对劲”？

### 来源

[X 原帖](https://x.com/derek_wall90176/status/2102198394047570412) · 2026-09-22（Asia/Shanghai）

### 适配模型

- 通用图像模型

### 示例

见 X 原帖媒体：https://x.com/derek_wall90176/status/2102198394047570412

### 提示词

```
请基于我上传的照片，制作一张独立的 3:4竖版“惊魂片场双生”海报。

画面上下严格 1:1分割。

上半部分

完整保留原始照片。

保持：

同一个人物

同一张脸

同一个动作

同一套服装

同一个场景
同一个拍摄角度
同一个构图
只做轻度统一调色，不改变照片内容。
下半部分
严格保持上半部分中的：
人物身份、面部特征、发型、服装、动作、姿态、主体位置、场景结构和构图不变。

将整个画面重构为一帧 90年代悬疑惊悚电影定格画面。

加入：

昏暗室内光线

冷暖混合灯光

VHS录像带颗粒

轻微色偏

低照度噪点
微弱镜头模糊
轻微曝光不稳定
老式录像质感
然后在原场景中选择一个合理位置：
门口 / 走廊 / 镜子 / 窗外 / 楼梯口 / 房间深处 / 停车场远处
加入一个模糊、距离较远、部分被遮挡的神秘人影。
要求这个人影：

不抢主体

不遮挡人物

不靠近镜头

不出现血腥元素

不出现具体影视IP角色
不复制现有恐怖电影人物
轮廓清晰但五官不可辨认
必须符合真实空间透视
必须符合现场光源方向
像原本就站在场景里
最终效果必须像：
原本是一张普通生活照，但后来才发现背景里多了一个不该出现的人。
禁止：
禁止换脸

禁止改动作

禁止改变人物年龄

禁止把场景完全换掉

禁止出现血腥
禁止肢体异常
禁止怪物贴脸
禁止夸张鬼脸
禁止满屏恐怖元素
禁止做成游戏海报
禁止明显AI插画感
```
